# 💖 Sai Ha'u nia Doben Valentine?

> Pájina interativu ne’ebe hau kria ho amor, atu ita-boot bele konfesa katak **"Hau hadomi ó!"** iha língua Tetum (Timor-Leste). Ho animasaun hati, butaun "Lakohi" ne’ebé lari, no mensajen romantis ida!

![Preview](Hugging.gif)

## 🌟 Fitor
- 🎮 **Interativu**: Butaun "Lakohi" lari tanba ha’u la bele haree rejeisaun!
- 💌 **Mensajen romantis iha língua Tetum** — husi Timor-Leste ba mundu hotu!
- 🎉 **Efetu konfeti** no **hujan hati** (hearts) bainhira ita-boot hakarak!
- 📱 **Responsivu**: Bele uza iha telefone ka komputador.
- 🌍 **Simples no limpu**: HTML, CSS, no JavaScript de’it — la iha framework!
